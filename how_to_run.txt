✅ Complete Pipeline Structure

vlm_pipeline/
├── configs/config.py           # All hyperparameters (quantization, LoRA, training)
├── models/models.py            # Qwen-VL & YOLO loaders with 4-bit quantization
├── utils/
│   ├── dataset_parser.py       # Auto-parse DHP + RxHand datasets
│   ├── augmentor.py            # Medical handwriting augmentations
│   └── metrics.py              # WER/CER/accuracy/mAP calculation
├── main.py                     # 3-stage orchestrator (augment/train/infer)
├── requirements.txt            # All dependencies
├── README.md                   # Complete usage guide
└── CLAUDE.md                   # Project documentation
🚀 Quick Start
1. Install Dependencies

pip install -r requirements.txt
2. Run Pipeline (3 switches at top of main.py)
Option A: Augmentation (generate processed datasets)


STAGE = "augment"
python main.py
Option B: Training (fine-tune Qwen-VL with LoRA)


STAGE = "train"
MODEL_CHOICE = "qwen-vl"
python main.py
Option C: Inference (run on samples & compute metrics)


STAGE = "infer"
python main.py

Gradient checkpointing enabled

Hugging Face Trainer with mixed precision fp16
TensorBoard monitoring
Auto checkpoint management
WER/CER/accuracy metrics
⚙️ Customization
Edit configs/config.py:


# Hardware (locked for 4GB safety)
per_device_train_batch_size = 1
gradient_accumulation_steps = 8

# Training
num_epochs = 3
learning_rate = 1e-4

# Debug mode (test with 5 samples)
cfg.dataset.max_samples = 5
